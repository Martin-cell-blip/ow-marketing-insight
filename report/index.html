03

官方 vs 二创：一个供给缺口，一个形态问题

回归以来官方主号单条均值 22.2 万播放，是 UGC 大盘的 3.3 倍——但只发了 15 条；官方电竞号发了 54 条，单条均值 3.9 万，反而低于 UGC 大盘。一个缺供给，一个缺形态。

◆
头部二创的效率：「兔了个狲」2 条视频均值 100 万（sora2 AI 二创）、「久子鸽」10 条均值 47 万——UGC 头部的单条效率是官方电竞号的 10-25 倍。

06

玩家之声：三个平台，三种声音

在内容与赛事数据之外，叠加 261 条 B 站热评 × 小红书三关键词一手扫描 × 知乎长期讨论做玩家痛点研究。最重要的发现不是某条痛点，而是平台分工——同一群玩家在不同平台说完全不同的话。

方法与可信性

数据源（全部公开）

  • B 站 web 搜索 API：5 关键词 × ≤50 页，视频元数据 3,354 条（原始）
  • B 站热评样本：87 个主题视频 × 前 3 条热评，共 261 条
  • Liquipedia：OWCS 2026 中国 Stage 1/2 + 世界总决赛页面 wikitext
  • OverFast API：英雄 / 职责 / 地图 / 模式元数据
  • 管线 Python + DuckDB，一键复现，原始数据含抓取时间戳
  • 补充定性源：小红书（标题级扫描）与知乎（主题归纳），仅用于 §06，不入库

清洗与边界（诚实优先）

  • R1 剔除挂机蹭激励计划视频（11 条）
  • R2 相关性过滤：剔除混入的英雄联盟内容（TES/MSI 等 167 条）
  • 搜索 API 为可见性样本，近期内容占优 → 趋势幅度不可直接引用
  • 赛事与节点事实标注来源与置信度；未经核验不写
